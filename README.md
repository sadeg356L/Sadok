# SADOK — معرض أعمال شخصي

موقع معرض أعمال عربي (RTL) بواجهة داكنة بنفسجية، ومشهد ثلاثي الأبعاد أصلي
مبني بـ Three.js. المشروع مبني بـ React + TypeScript + Vite، ويعمل كصفحة
واحدة (single page) قابلة للنشر على GitHub Pages.

المحتوى حقيقي: المشاريع الثلاثة موجودة على الإنترنت، ولكل مشروع رابط مباشر
ومستودع قابل للفحص. لا توجد أرقام خبرة أو شهادات أو عملاء أو إحصائيات
مُختلقة.

## التقنيات

| الطبقة | المستخدم |
| --- | --- |
| الواجهة | React 18، TypeScript |
| البناء | Vite 5 |
| الحركة | GSAP 3 (core + ScrollTrigger) |
| ثلاثي الأبعاد | Three.js (WebGL) |
| الأيقونات | react-icons |
| التنسيق | CSS خام بمتغيّرات تصميم (design tokens) |
| الخطوط | IBM Plex Sans Arabic + Space Grotesk |

لا توجد مكتبات واجهة جاهزة (لا Tailwind، لا UI kit) ولا GSAP Club plugins.
التمرير طبيعي، ونصوص العربية تُقسَّم على مستوى الكلمة فقط.

## تعديل المحتوى

**كل ما تحتاج تعديله موجود في ملف واحد:** `src/data/content.ts`.

| ما تريد تغييره | المفتاح في `content.ts` |
| --- | --- |
| الاسم، العمر، الموقع، النبذة | `profile` |
| روابط القائمة | `navLinks` |
| أرقام/حقائق الهيرو | `heroFacts` |
| الشريط المتحرك | `marqueeWords` |
| المهارات | `skillGroups` |
| طريقة العمل | `approach` |
| المشاريع (الاسم، الوصف، الروابط، الصورة) | `projects` |
| قسم التواصل | `contact` |

ملاحظات مهمة عند التعديل:

- **البريد الإلكتروني** الحالي مأخوذ من موقعك المنشور مسبقًا، وموثّق في
  تعليق داخل `content.ts` كقيمة قابلة للاستبدال. غيّره إن أردت عنوانًا آخر.
- **لا تضف نسبًا مئوية للمهارات** (مثل "React 90%")؛ التصميم لا يستخدمها
  لأنها غير قابلة للتحقق.
- **أسماء المشاريع** هي الأسماء الحالية على المواقع الحيّة:
  KHOTWA و NAWAH و AUREON. حقول `aka` تحتفظ بالأسماء القديمة للتعريف فقط.
- **صور المعاينة** في `public/previews/` هي رسومات SVG أصلية وموسومة
  "ILLUSTRATIVE PREVIEW". استبدلها بلقطات حقيقية إن أردت.
- بعد تعديل الروابط، أعد التحقق منها يدويًا. لا يوجد اختبار روابط آلي.
- النص العربي يُقسَّم بالكلمات عبر `splitText.ts`. لا تستبدله بتقسيم
  الحروف، لأن ذلك يقطع اتصال الحروف العربية.

## المشهد ثلاثي الأبعاد

الشخصية `SADOK // VESPER` ليست نموذجًا محمّلًا من ملف، بل مبنية بالكود بالكامل:

- جمجمة/وجه/فك/أنف/شفاه/أذنان من شبكة كروية مشوّهة إجرائيًا، مع تجويفين للعينين.
- عينان كرويتان بأيريس وبؤبؤ، وجفنان علوي وسفلي متحركان، ورموش وامضة.
- حاجبان وشعر هندسي حديث وخامة بشرة/قماش بنفسجي، وبيئة استوديو مرسومة على canvas.
- الرأس يتبع المؤشر (yaw ±0.46، pitch ±0.24) والعينان تتحركان ضمن حدود تشريحية مستقلة، مع damping ناعم وعودة للمركز.
- رمش دوري كل 2.9–7.2 ثانية، ورمشة يدوية متاحة للاختبار في وضع التطوير.
- الكاميرا تتكيّف مع نسبة العرض/الارتفاع كي يبقى الرأس والكتفان داخل الإطار.
- تنظيف كامل للهندسات والمواد والنسيج والـrenderer عند إزالة المكوّن.

الملف `Character/Scene.tsx` يُحمَّل بشكل lazy، لذلك لا يدخل Three.js في
الحزمة الأولى. تم فحص البكسلات فعليًا للتأكد من أن المشهد يُرسم ولا يظهر
كـcanvas فارغ. التفاصيل في `TEST_REPORT.md`.

## الأداء والوصولية

- لا يوجد تمرير سلس اصطناعي (`ScrollSmoother`)؛ التمرير طبيعي ويحترم إعدادات
  النظام.
- الحركات تعتمد `opacity` بدل `visibility`، فيبقى المحتوى قابلاً للقراءة
  حتى لو تعطّلت الحركة.
- `prefers-reduced-motion: reduce`:
  - يُلغى تقديم الهيرو،
  - يُزال المؤشر المخصص،
  - تظهر كل العناصر مباشرة.
- المؤشر المخصص يعمل على أجهزة المؤشر الدقيق فقط، ولا يظهر على اللمس.
- رابط تجاوز إلى المحتوى (skip link)، هيكل عناوين صحيح، وتباين ألوان
  بين 8.04:1 و12.41:1.
- لا تمرير أفقي عند 320 / 768 / 1440 / 1920 بكسل.
- عند تعذّر WebGL يُلتقط الخطأ داخل `ErrorBoundary` بدل إفراغ الصفحة.

## النشر على GitHub Pages

المشروع جاهز للنشر عبر GitHub Actions:

1. المستودع موجود على GitHub: `https://github.com/sadeg356L/Sadok` (فرع `main`).
2. في المستودع: **Settings → Pages → Build and deployment → Source = GitHub Actions**.
3. سيستخدم الـworkflow الموجود في `.github/workflows/deploy.yml`:
   `npm ci` → `npm run build` → رفع `dist/` → النشر.

`vite.config.ts` يستخدم `base: "./"`، لذا يعمل البناء على مسار مشروع
(`username.github.io/repo/`) وعلى نطاق مخصص دون تعديل.

`public/.nojekyll` موجود حتى لا يتجاهل GitHub Pages الملفات التي تبدأ بشرطة
سفلية.

> **مهم:** بعد الدفع، فعّل Pages مرة واحدة من **Settings → Pages → Source =
> GitHub Actions**. الـworkflow يعمل تلقائيًا عند كل دفع إلى `main`.

## قيود معروفة

1. **روابط Open Graph مطلقة نحو GitHub Pages.** تشير `og:image` و`twitter:image`
   إلى `https://sadeg356L.github.io/Sadok/og.png`، والـJSON-LD إلى نفس النطاق.
   إن غيّرت اسم المستودع أو أضفت نطاقًا مخصصًا، حدّث هذه الروابط في `index.html`.
2. **الترخيص PPL يمنع الاستخدام التجاري** — راجع `LICENSE` قبل النشر.
3. **الشخصية إجرائية وليست مسحًا واقعيًا.** لا توجد عظام أو حركات معتمدة على
   skeletal animation؛ الرأس والعينان فقط يتحركان. ملامح الوجه أسلوبية
   (stylized)، وفتحة العين اليسرى أضيق قليلًا من اليمنى بسبب الشعر والتجويف،
   وقد تظهر الحافة الخارجية للصلبة أوسع من الداخلية في بعض الزوايا.
4. **على الهواتف (390×844) يقع المشهد أسفل الشاشة الأولى** بعد نص الهيرو؛
   الرأس والكتفان ظاهران، لكن الجزء السفلي من التمثال يتطلب تمريرًا بسيطًا.
5. **حجم حزمة Three.js** ~543 كيلوبايت (142 كيلوبايت مضغوطة)، لكنها lazy
   ولا تدخل التحميل الأول.
6. **قسم `#approach` غير موجود في القائمة** عن قصد لإبقاء التنقل قصيرًا.
7. **صور المعاينة توضيحية** وليست لقطات حقيقية من المشاريع.
